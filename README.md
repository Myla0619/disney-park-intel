# Disney Park Intelligence

[English](README_EN.md) | 中文

去上海迪士尼，想多拍照、带孩子轻松玩，还是专门挑战刺激项目，都可以有一条适合自己的路线。

Disney Park Intelligence 会结合游玩时间、同行人、项目偏好、排队时间、步行距离和预约安排，帮你规划当天的行程。进园晚了、临时改变主意，或者已经提前玩完一个项目，也可以从当前时间重新安排后面的路线。

## [打开网页](https://disney-park-intel.vercel.app)

### 它能帮你做什么

- **按你的玩法规划路线**：拍照、亲子、刺激项目或混合游玩，都能参与路线选择，而不是套用同一份攻略。
- **少排队，也少走回头路**：综合项目等待时间和园区位置，安排更顺路的游玩顺序。
- **替你读评价**：从公开游记和评论中找出与当前项目或餐厅真正相关的内容，帮你快速了解体验、避雷点和适合人群。
- **记住不能错过的时间**：把餐厅预约、巡游和烟花放进行程，在安排其他项目时为它们留出时间。
- **当天随时重排**：实际进度和原计划不一样时，从“现在”继续规划，不需要重做整天的行程。
- **直接问具体问题**：比如“附近有什么适合拍照的地方”“孩子 110cm 能玩什么”或“接下来去哪儿更省时间”。

排队、演出和预约情况可能随时变化，请以迪士尼官方 App 当天的信息为准。
