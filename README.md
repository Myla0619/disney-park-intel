# Disney Park Intelligence

[English](README_EN.md) | 中文

去上海迪士尼之前，我们常常收藏很多攻略；真正进园以后，问题却变成了：现在先去哪里、要排多久、孩子能不能玩、预约餐厅会不会来不及。

这个网站把这些事情放进同一份行程里。你填好日期、同行人和偏好，它会排出一条当天可以照着走的路线。

## [打开网页，开始规划](https://disney-park-intel.vercel.app)

不用下载，也不用注册。

### 怎么用

1. 选择游玩日期和大致的入园、离园时间。
2. 填写同行孩子的身高，选择想玩的类型和已经购买的尊享卡。
3. 如果订了餐厅、想看巡游或烟花，把时间一起填进去。
4. 生成行程后，可以查看项目详情、排队情况、餐厅和拍照点。
5. 当天玩完一个项目，点“完成并重排剩余行程”。网站会从当前时间继续安排，不会让你回头重做上午的计划。

也可以直接问网页里的助手，比如：

- “现在排队最短的是哪个项目？”
- “我在宝藏湾，接下来去哪里？”
- “小朋友 110cm，有哪些项目不能玩？”
- “帮我找一家不用预约的餐厅。”

### 你会看到什么

- 按时间排列的游玩路线，包括步行、用餐和演出。
- 项目等待时间、身高要求和适合人群。
- 来自公开游记的相关片段，视频笔记会标为 `[视频]`。
- 项目和餐厅详情页里的个人评分。评分目前只保存在这台设备上。

### 使用时请留意

排队时间会随时变化，演出、烟花和预约信息请以迪士尼官方 App 当天公布的内容为准。网络或数据源不可用时，网站可能显示历史估计或带说明的参考数据。

自动生成的行程是一份建议，不是园区保证。临时闭园、天气、同行人的状态，都可能让现场情况发生变化。
