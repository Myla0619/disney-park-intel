# Disney Park Intelligence

[English](README_EN.md) | 中文

**为上海迪士尼打造的 AI 行程助手。**

它把你的入园时间、同行人身高、游玩偏好、餐厅预约、尊享卡、实时排队和园区距离放进同一张时间表，给出一条到园后可以直接照着走的路线。

[在线体验](https://disney-park-intel.vercel.app)

> 不再对着攻略临时拼行程。告诉它“和谁来、想玩什么、几点必须到哪里”，剩下的交给规划器。

## 从入园前到闭园

### 1. 告诉应用今天怎么玩

选择带娃、刺激、轻松、拍照或购物美食模式，并填写：

- 入园与离园时间
- 孩子的年龄和身高
- 效率、均衡或省力路线
- 已购买的尊享卡套餐
- 餐厅预约、花车巡游和烟花时间
- 必玩项目、拍照和购物偏好

### 2. 获得一张可执行的全天时间表

应用会把项目、步行、用餐、演出、拍照和购物排进同一条时间轴。预约和演出作为固定锚点，其他活动围绕它们安排，并自动避开身高不符或时间放不下的项目。

### 3. 在园区里随时调整

计划不是一次生成后就不再变化。你可以：

- 根据当前等待时间重新规划
- 告诉助手“我现在在宝藏湾，下一站去哪”
- 询问适合孩子的项目、拍照时间或无需预约的餐厅
- 长按行程条目进行替换、前移、后移或删除
- 收藏想玩的项目，并让路线围绕心愿单重新排序

## 核心体验

| 场景 | 应用如何帮助你 |
|---|---|
| 少排队 | 综合实时等待、历史快照和项目时长安排顺序 |
| 少走冤枉路 | 按项目之间的实际位置计算连续步行成本 |
| 带孩子同行 | 根据每位孩子的身高过滤不适合乘坐的项目 |
| 已有预约 | 把餐厅、巡游和烟花固定在时间轴上，其他项目自动避让 |
| 买了尊享卡 | 识别单项卡和套餐，并在合适的时段使用 |
| 临时改变计划 | 通过自然语言查询现场信息或重新安排行程 |
| 网络不稳定 | 已访问的主要页面支持缓存，核心评分可退回本地规则 |

## AI 助手能回答什么

应用内的助手不仅提供聊天回复，还能调用等待时间、评论检索、地点信息和行程规划工具。例如：

```text
现在哪个项目等待最短？
我在宝藏湾，下一步去哪？
我女儿 5 岁、身高 108cm，适合玩哪些？
最佳拍照时间和地点是？
帮我重新安排下午，但保留 17:30 的餐厅预约。
```

工具执行过程会实时显示，回答依据来自应用数据，而不是让模型凭空编一条路线。

## 推荐如何产生

```text
同行人 + 偏好 + 时间与预约
              ↓
      过滤不可行的候选项目
              ↓
实时等待 → 历史预测 → 静态基线
              ↓
  排队、步行、体力与偏好综合排序
              ↓
  插入用餐 / 演出 / 拍照 / 购物
              ↓
       生成全天时间表与说明
```

时间、身高、尊享卡间隔和预约冲突由确定性规则处理；AI 负责理解自然语言、选择工具和解释建议。即使 AI 服务暂时不可用，基础评分与行程能力仍可使用本地规则运行。

## 当前覆盖

- 上海迪士尼乐园
- 24 个游乐项目
- 11 家餐厅
- 29 家商店
- 44 个拍照位置
- 14 个项目的 280 条公开游玩笔记
- 1,300+ 条版本化等待时间快照

东京、香港、巴黎和美国园区暂未开放。

## 数据状态与降级

| 能力 | 主要来源 | 数据不可用时 |
|---|---|---|
| 实时等待 | themeparks.wiki | 使用静态基线，并明确标记为 fallback |
| 等待预测 | 历史等待快照 | 样本不足时从当前快照外推并降低置信度 |
| 项目评论 | 离线收集的公开小红书笔记 | 未覆盖项目展示明确标记的示例内容 |
| AI 评分 | 模型的结构化输出 | 自动切换到本地评分规则 |
| 会话状态 | 内存，可选 Upstash Redis | 无 Redis 时冷启动后重新开始会话 |

### 使用边界

- 等待时间、开放状态、演出和餐厅信息可能随时变化，请以乐园官方现场信息为准。
- 小红书没有星级，数据中的 `rating` 是热度代理，不代表满意度。
- 餐厅真实评论尚未完整覆盖，相关结果可能使用降级数据。
- 本项目不是上海迪士尼度假区或 The Walt Disney Company 的官方产品。

## 本地运行

```bash
git clone https://github.com/Myla0619/disney-park-intel.git
cd disney-park-intel
npm install
cp .env.local.example .env.local
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。如需启用完整 AI 助手，请配置 Claude 凭证，或连接兼容接口的自训模型服务；未配置模型时仍可体验本地评分和基础行程。

## 技术概览

- Next.js 14、TypeScript、Tailwind CSS、Zustand
- Claude / 自训模型工具调用与 SSE 流式响应
- BM25 中文检索、实时等待服务与历史预测
- Vitest、GitHub Actions、Vercel，可选 Upstash Redis

开发者可从以下目录继续了解实现：

```text
src/app/                 产品页面与 API
src/app/api/agent/       AI 助手与工具调用
src/lib/routing.ts       行程规划与约束处理
src/lib/wait-*.ts        实时等待与历史预测
src/lib/vector-store.ts  评论检索
data/                    评论与等待时间数据
```

测试与研究材料保留在 `src/lib/__tests__/`、`scripts/`、`rl/` 和 `docs/`，但它们不是产品体验的前置条件。
