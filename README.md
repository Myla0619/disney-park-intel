# Disney Park Intelligence

[English](README_EN.md) | 中文

一个面向上海迪士尼的行程规划项目。把排队时间、步行距离、身高限制、餐厅预约和个人偏好放在一起，给出当天可参考的安排。

[在线体验](https://disney-park-intel.vercel.app)

## 功能

- 根据同行人、入离园时间和尊享卡选择安排路线。
- 查询排队时间，结合历史快照估计等待情况。
- 按项目名称和别名筛选笔记，截取相关文字；视频笔记标为 `[视频]`。
- 在项目和餐厅详情页记录个人评分，目前保存在当前设备。
- 当天完成项目后，可点击“完成并重排剩余行程”；进度按园区和日期保存。
- 通过聊天查询项目、餐厅、商店和拍照点。

## 实现

路线由确定性代码计算，模型负责理解问题、调用工具和解释结果。排程综合等待、步行和体力成本，并处理固定时段。它是启发式安排，不保证全局最优。

网站支持 Claude 和自训模型两条调用路径。自训模型复用训练环境的提示词、工具表和文本协议；服务不可用或超时后，可自动切换 Claude。页面不显示模型切换提示。启用自训模式时，项目评分和行程备注使用本地逻辑。

接入代码已提交，但尚未完成自训权重的线上部署验证。部署步骤见 [自训模型部署](docs/student-deployment.md)。

## 数据和限制

实时等待来自外部服务，历史等待和笔记来自仓库语料。数据不足时会使用带标记的降级结果或示例，不能把它们当作现场实测。

小红书笔记中的 `rating` 是按互动量生成的热度指标，不是作者给出的星级。站内个人评分与它分开保存。评论匹配目前依靠关键词和别名，还不能可靠理解所有简称、反讽或一篇笔记中多个项目的评价归属。餐厅样例也不代表真实用户反馈。

项目暂无可验证的活跃用户或留存统计。语料条数和测试题数不等于用户数。

## 本地运行

```bash
git clone https://github.com/Myla0619/disney-park-intel.git
cd disney-park-intel
npm install
cp .env.local.example .env.local
npm run dev
```

打开 [localhost:3000](http://localhost:3000)。未配置模型服务时，路线仍可使用本地逻辑，聊天需要有效的模型凭证。密钥只放在环境变量中；不使用的凭证变量应删除，不要留空值覆盖其他配置。

## 验证和训练

```bash
npm test
npm run eval:retrieval
```

测试覆盖排程、数据映射、检索和工具协议。历史评测见 [评测目录](data/rl/eval/README.md)，这些结果不能作为当前代码或线上模型的最新成绩。修改后需要重新运行对应评测。

`rl/` 包含数据生成、蒸馏、SFT、GRPO 和完整工具循环评测。现存旧实验权重是 Qwen 32B 的 QLoRA/SFT 与 GRPO adapter；仓库中的全参训练配置是后续方案，不代表已经完成全参训练。新训练步骤见 [训练说明](rl/train/README.md)。

## 目录与维护

- `src/app/`：页面和接口。
- `src/lib/`：排程、检索、会话和模型接入。
- `rl/`：训练工具环境、数据管线和评测。
- `data/`：笔记、等待快照和实验记录。
- `scripts/`：采集与验证脚本。
